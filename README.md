# MGRSTool

Мінімальний веб-додаток: **MGRS → широта/довгота WGS84**.

Немає збірки, сервера, фреймворків. Три ваших файли + одна готова бібліотека.

## Як запустити

Відкрийте `index.html` у браузері (подвійний клік або File → Open).

Інтернет не потрібен: конвертер лежить у `vendor/mgrs.min.js`.

## З чого складається

| Файл | Роль (аналог з Apple) |
| --- | --- |
| `index.html` | Екран: поле вводу, кнопки, місце для результату |
| `styles.css` | Зовнішній вигляд |
| `app.js` | Логіка екрана: прочитати текст → конвертувати → показати |
| `vendor/mgrs.min.js` | Готова математика MGRS/UTM (як залежність з SPM) |

Потік: користувач вводить рядок → `app.js` прибирає пробіли і робить uppercase → `mgrs.toPoint()` повертає `[довгота, широта]` → числа показуються на екрані.

## Куди дивитись новачку

1. `index.html` — які є елементи (`id="mgrs"`, кнопки, блок результату).
2. `app.js` — функція `convert()`. Це весь застосунок.
3. Кнопка «Приклад» підставляє `33TWN0838825205` (зона 33T, Італія).

Формат MGRS: зона + літера широти + квадрат 100 км + парне число цифр (істинг, потім норфінг). Результат — десяткові градуси WGS84, широта першою.
